Бюджет зараз зберігається лише на цьому пристрої. Щоб він був спільним на всіх телефонах — створи таблицю в Supabase → SQL Editor:

create table budgets (month text primary key, data jsonb not null, updated_at timestamptz default now());
alter table budgets enable row level security;
create policy "budgets_all" on budgets for all using (true) with check (true);
